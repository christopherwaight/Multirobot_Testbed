# Velocity Plots Output Directory

This directory contains velocity plots generated by the VF_Robot simulation system.

## File Naming Convention

Velocity plots are automatically saved with the following naming pattern:

```
{environment_name}_velocity_{field_mode}.png
```

**Examples:**
- `sink1_velocity_analytical.png` - Sink 1 environment using analytical field
- `vortex1_velocity_nn.png` - Vortex 1 environment using neural network field
- `sinking_vortex1_velocity_blended.png` - Sinking Vortex 1 using blended RBF/NN field

## Plot Contents

Each velocity plot contains:

1. **Individual robot velocity subplots** - One for each robot showing velocity magnitude over time
2. **Combined comparison subplot** - All robots overlaid on one plot for easy comparison

**Y-axis**: Velocity magnitude in m/s
**X-axis**: Time in seconds (timestep × step_number)

## Generating Plots

### Automatic Generation (Multi-Environment Mode)

Run the main simulation with velocity plotting enabled:

```bash
cd /path/to/VF_Robot
python3 experiments/main_omni.py
```

Ensure in `main_omni.py`:
```python
SIMULATION_MODE = "multi_env"
SAVE_VELOCITY_PLOTS = True
```

This will generate one plot per environment (6 plots for variant 1 environments).

### Single Environment

```python
# In main_omni.py
SIMULATION_MODE = "single"
ENVIRONMENT = "sink1"
SAVE_VELOCITY_PLOTS = True
```

### Manual Generation

Use the standalone plotting script:
```bash
python3 experiments/plot_velocities.py
```

## Interpretation

### Sink Fields
- Velocities typically **increase** as robots approach the sink
- All robots should show similar velocity patterns if formation is maintained

### Source Fields
- Velocities typically **decrease** as robots move away from source
- May show diverging trajectories

### Vortex Fields
- Velocities should **stabilize** in circular orbits
- Look for steady-state velocity magnitudes

### Saddle Points
- Velocities may **oscillate** near the unstable equilibrium
- Expect irregular patterns compared to sinks/sources

### Sinking/Spewing Vortex
- Combination of rotational and radial components
- Velocities change as radius changes

## Configuration

To change velocity plot settings, edit `experiments/main_omni.py`:

```python
# Enable/disable velocity plotting
SAVE_VELOCITY_PLOTS = True

# Output directory (this directory)
VELOCITY_PLOT_DIR = "velocity_plots"
```
