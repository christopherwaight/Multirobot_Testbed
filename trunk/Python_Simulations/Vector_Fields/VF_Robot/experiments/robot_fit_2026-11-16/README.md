# Robot model fit, 2026-11-16

Scripts and printed outputs behind the 2026-11-16 Decabot model (gain 0.86, delay 0.055 s, lag 0.02 s, dead zone 0.025 m/s, cap 0.3 m/s). The method and the decisions are in `SIM_RERUN_PLAN_2026-11-16.txt` at the repo root. These files were copied here on 2026-11-19 from a session scratchpad that a reboot can clear.

Order of use:

1. `load_runs.py <campaign root> runs.pkl` reads every run of the 2026-11 campaign into per-robot command and velocity sequences. Read `New_Hardware_Data/data_hardware_campaign_11_11_2026/README_STALE_VARIABLES.md` first.
2. `fit.py` and `fit2.py` fit the response model to those runs. Their printed results are `fit_out.txt`, `fit2_out.txt` and `fit3_out.txt`.
3. `physics_fit.py` repeats the fit with physical parameters (`physics_out.txt`).
4. `closed_loop.py` checks the fitted model in closed loop (`closed_loop_out.txt`).
5. `leadsim/` holds the estimate-lead simulation, and `oldbot/omnibot_head.py` the legacy `Omnibot` for comparison.

`runs.pkl` and the other pickles are regenerated by step 1 and are not kept. Neither campaign has commands below 0.06 m/s, so the dead zone value is set by where the robots stop, not by a direct low-speed test.
